# 4FusionLab organization profile

Public profile and visual assets for [4FusionLab](https://github.com/4FusionLab).

- `profile/README.md` — the organization's public Overview.
- `assets/banner.svg` — profile banner, with editable vector artwork.
- `assets/avatar.svg` — geometric 4F organization avatar source.
- `assets/avatar.png` — raster avatar for GitHub's profile picture upload.

Project documentation and support belong in the [Perfora](https://github.com/4FusionLab/Perfora) and [Selectra](https://github.com/4FusionLab/Selectra) repositories.
