# Политика безопасности

[English](SECURITY.md)

Если вы считаете, что нашли уязвимость в репозитории 4FusionLab или конвейере релизов, **не публикуйте пригодные для эксплуатации подробности в открытом GitHub Issue**.

Используйте закрытую отправку сообщений об уязвимостях GitHub / Security Advisories, если она включена для репозитория, либо свяжитесь с сопровождающими по существующему частному каналу.

Полезно указать затронутый аддон и версию, операционные системы, серьёзность и последствия, закрытые шаги воспроизведения и предлагаемый способ устранения. Никогда не включайте в публичные отчёты учётные данные, CAD-документы клиентов, персональные данные и конфиденциальные токены.

Исправления безопасности тестируются и распространяются в соответствии с той же политикой GitVersion для изменений исполняемых компонентов, что и другие исправления. Правила отдельного продукта могут быть строже.
