# Профиль организации 4FusionLab

[English](README.md)

Публичный профиль и визуальные материалы [4FusionLab](https://github.com/4FusionLab).

- `profile/README.md` — общедоступная страница организации.
- `assets/banner.svg` — баннер профиля с редактируемой векторной графикой.
- `assets/avatar.svg` — векторный исходник геометрического аватара 4F.
- `assets/avatar.png` — растровый аватар для загрузки в профиль GitHub.

Документация и поддержка продуктов находятся в отдельных репозиториях: [Perfora](https://github.com/4FusionLab/Perfora) (перфорация), [Selectra](https://github.com/4FusionLab/Selectra) (выбор похожей геометрии), [Ejix](https://github.com/4FusionLab/Ejix) (извлечение объёмов), [RuEn](https://github.com/4FusionLab/RuEn) (горячие клавиши при русской раскладке) и [Planara](https://github.com/4FusionLab/Planara) (планируемая развёртка поверхностей).
