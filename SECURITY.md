# Security policy

If you believe you have found a security vulnerability in a 4FusionLab repository or release pipeline, **do not post exploitable details in a public GitHub Issue**.

Use GitHub's private vulnerability reporting / Security Advisories when enabled for that repository, or contact its maintainers through an existing private communication channel.

Useful information: affected add-in and version, affected operating systems, severity and impact, private reproduction steps, and proposed mitigation. Never include credentials, customer CAD documents, personal data or sensitive tokens in public reports.

Security changes are tested and distributed under the same runtime-change GitVersion release policy as other fixes. Product-specific instructions may be stricter.
